## Iris loop

An eye turns into a grandfather clock, then the Earth (with the Moon and a satellite), then a sunset beach, then a pair of hands, and back to the eye. 30-second loop, coloured text only.

![iris loop](iris_loop_preview.gif)

```sh
python3 iris_loop.py
```

- Looks best in a 150x56 window. On a Mac, double-click `iris.command` and it sizes the window for you.
- If macOS says it can't verify `iris.command`, use the `python3` command above instead.
- Python 3.8+, no dependencies; the images are built into the script.
- Ctrl-C to quit. `python3 iris_loop.py --check` runs a quick self-test.
